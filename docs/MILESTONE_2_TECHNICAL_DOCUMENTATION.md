## 1. Project Title and Abstract

**Title:** Personalized TED Talks Recommendation System Using Machine Learning  
**Abstract:**  
With thousands of high-impact talks spanning technology, science, global issues, humanities, and design, discovering relevant and serendipitous TED talks remains a formidable discovery challenge for users. This project engineers an enterprise-grade, content-based, semantic, and hybrid recommendation system tailored for TED Talks. The system leverages multi-field Term Frequency-Inverse Document Frequency (TF-IDF) feature representations combined with deep semantic embeddings generated by pretrained Sentence Transformers (`all-MiniLM-L6-v2`). It integrates multi-signal preference blending (seed talk, session history, multiple liked talks, negative exclusions, and user-selected topical interests), Maximal Marginal Relevance (MMR) for diversification, and an intrinsic explainability engine that produces transparent natural language justifications for every recommendation. Extensive automated testing, benchmark latency analysis, and modular software design ensure full reproducibility and operational readiness.

---

## 2. Problem Statement

TED hosts over 2,500 talks delivered by global innovators and thought leaders. While diverse, the sheer volume of content causes choice paralysis and poor content discovery. Traditional keyword search often retrieves overly narrow results or misses conceptually related talks that use different vocabularies. Furthermore, users often seek talks based on evolving interests, multiple liked topics, or specific themes while avoiding repetitive talks or previously viewed content.

The technical objective is to design, implement, and benchmark an intelligent recommendation engine capable of:
1. Recommending talks similar to a given seed talk based on content semantics and editorial metadata.
2. Generating recommendations from free-form user interest queries and topic tags.
3. Personalizing recommendation slates based on multiple liked talks while strictly excluding disliked or seen talks.
4. Balancing relevance and novelty through diversity-aware re-ranking.
5. Providing verifiable, human-interpretable explanations for each recommended item.
6. Operating with sub-100ms retrieval latency on commodity computing hardware.

## 12. Preprocessing Decisions

1. **Transcription Cue Removal:** Regex substitution removes parenthetical annotations (`\([A-Za-z\s]+\)`).
2. **HTML & URL Stripping:** Strips any embedded HTML tags or external hyperlinks.
3. **Case Normalization:** Converts text to lowercase.
4. **Preservation of Negation:** Avoids blind removal of negation words (`not`, `never`, `no`) so semantic sentiment and meaning remain intact.
5. **Missing Transcript Fallback:** When a talk lacks a transcript, the pipeline substitutes the detailed description with duplicated weight, ensuring the talk receives proper feature representation rather than being excluded from recommendations.

Feature engineering constructs specialized text signals across four distinct fields:
- **Title Feature:** Captures concise, high-salience topic signals.
- **Description Feature:** Captures synthesized editorial summary.
- **Tags Feature:** Captures curated taxonomy classifications.
- **Transcript Feature:** Captures rich, detailed vocabulary and nuanced subtopics.

## 14. TF-IDF Design and Configuration

- **Hyperparameters:**
  - `ngram_range`: (1, 2) — captures unigrams and bigrams (e.g., `climate change`, `machine learning`).
  - `min_df`: 2 — drops rare typos and idiosyncratic noise appearing in only 1 talk.
  - `max_df`: 0.90 — filters corpus-wide high-frequency words.
  - `sublinear_tf`: True — replaces term frequency $tf$ with $1 + \log(tf)$ to prevent long transcripts from disproportionately dominating similarity.
  - `stop_words`: `"english"`.
- **Field-Specific Max Features:**
  - Title: 5,000 terms
  - Description: 10,000 terms
  - Tags: 5,000 terms
  - Transcript: 30,000 terms
- **Combined Dimension:** Stacked sparse representation yields **44,613 features** across all 2,550 talks.

---

## 15. Embedding Model and Configuration

- **Pretrained Architecture:** `sentence-transformers/all-MiniLM-L6-v2`
- **Embedding Dimensionality:** 384 dimensions (dense float32 vectors)
- **Sequence Length:** 256 tokens max sequence length
- **Input Composition:** Title + Description + Tags + Transcript key excerpt (first 1,200 characters)
- **Normalisation:** Unit L2 normalisation applied so that inner dot product strictly equals cosine similarity.
- **Caching:** Saved locally at `Module_3_Feature_Engineering_Vectorization/embeddings/ted_semantic_embeddings.npy` to eliminate redundant re-computation.

---

## 16. Similarity Calculation

For both TF-IDF and dense embeddings, vectors are L2-normalized:
$$\|\mathbf{u}\|_2 = 1, \quad \|\mathbf{v}\|_2 = 1$$

Cosine similarity simplifies to standard dot product:
$$\text{Sim}(\mathbf{u}, \mathbf{v}) = \mathbf{u} \cdot \mathbf{v}$$

- For TF-IDF: Computed via fast sparse-dense matrix multiplication: $\mathbf{S}_{\text{tfidf}} = \mathbf{X}_{\text{sparse}} \mathbf{q}^T$.
- For Embeddings: Computed via vectorized matrix multiplication: $\mathbf{S}_{\text{semantic}} = \mathbf{E} \mathbf{q}_{\text{emb}}$.

## 20. Hybrid Scoring Design and Justification

The hybrid score combines multiple complementary signals:
$$S_{\text{hybrid}}(i) = w_{\text{tfidf}} \cdot S_{\text{tfidf}}(i) + w_{\text{semantic}} \cdot S_{\text{semantic}}(i) + \text{Boost}_{\text{interests}}(i)$$

- **Default Weights:** $w_{\text{tfidf}} = 0.5$, $w_{\text{semantic}} = 0.5$.
- **Rationale:** Lexical matching ensures high-precision keyword alignment, while semantic embeddings provide broad conceptual recall. Combining them achieves superior retrieval quality compared to either model in isolation.
- **Topic Boost:** Talks sharing explicit user interest tags receive an additive boost of up to 0.30.

---

## 21. Personalisation Strategy

- **Seed Talk Discovery:** Generates talks similar to a single target talk.
- **Multi-Liked Aggregation:** Users can provide a set of liked talks. The engine computes the centroid representation across all liked talks in both TF-IDF and embedding spaces.
- **Negative Feedback (Disliked Talks):** Disliked talks are excluded from candidate generation.
- **Topic Interest Blending:** Incorporates user-specified interests into the scoring function.

---

## 22. Diversity and Ranking Approach (MMR)

To eliminate redundant recommendations (e.g. returning 5 talks all on the same narrow sub-topic), we implement **Maximal Marginal Relevance (MMR)**:
$$\text{MMR} = \arg\max_{d_i \in C \setminus S} \left[ \lambda \cdot \text{Sim}(d_i, q) - (1 - \lambda) \cdot \max_{d_j \in S} \text{Sim}(d_i, d_j) \right]$$
- $\lambda = 0.70$: Balances 70% relevance to user query/seed and 30% diversity relative to already selected recommendations.

## 23. Collaborative Filtering Feasibility and Data Limitation

### Technical Audit
- **Dataset Analysis:** The TED Talks dataset contains only talk-level aggregate statistics (`views`, `comments`, and aggregate emotion tallies such as `[{'name': 'Inspiring', 'count': 1050}]`).
- **Absence of User Data:** There are zero individual user identifiers, zero individual watch histories, and zero per-user rating matrices.
- **Engineering Decision:** To maintain strict research and engineering integrity, **no synthetic user accounts or fake interactions were fabricated**. Collaborative filtering (e.g. ALS, matrix factorisation) is documented as **UNSUPPORTED BY AVAILABLE EVIDENCE**.
- **Future Integration:** We have designed the `CollaborativeSignalProvider` interface in `ted_recommender.collaborative`, providing a pluggable contract for when genuine user telemetry is collected.
